Behind the model · equations, units & assumptions

Single Phase Darcy's Law

Q = kA ΔP / (μL)   ·   ṁ = ρQ

Across the fault: the same flow passes through all three units. Resistances Rᵢ = μLᵢ / (kᵢA) add, so Q = ΔP / ΣRᵢ. Pressure drops in proportion to each resistance.

Along the fault: each path has the same pressure drop. Conductances Cᵢ = kᵢAᵢ / (μL) add, so Q = ΔP ΣCᵢ. Flow divides in proportion to each conductance.

At fixed pressure, the along-fault comparison shows total mass flow versus fault permeability; rock and fault flow contributions add to the total. At fixed mass flow, it shows the pressure required through combined paths, the two rock paths alone, or the fault alone, retaining each path's area. These reference pressures do not add.

Constants & scope

Water density ρ = 1,000 kg/m³; dynamic viscosity μ = 5.5 × 10⁻⁴ Pa·s. 1 mD = 9.869233 × 10⁻¹⁶ m²; 1 bar = 100,000 Pa. Permeability sliders use a logarithmic scale; the number fields show mD directly.

Steady, one-dimensional, saturated, single-phase Darcy flow with constant fluid properties and uniform permeability within each unit. Both rock units share one permeability. Across the fault, both rock lengths are equal and A = 200 × 200 m². Along it, total cross-section is 200 m wide × 200 m high; fault thickness changes the partition of that fixed area.

These idealised models isolate permeability and geometry. They do not include gravity, storage, transient flow, or fracture opening. Diagram proportions are adjusted when a layer is too thin to see.
